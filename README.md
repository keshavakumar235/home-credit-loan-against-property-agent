# Home Credit — Loan Against Property Voice Agent

An AI-powered voice agent built with Retell AI to conduct preliminary eligibility assessments for a potential Home Credit Loan Against Property (LAP) offer of up to ₹75,00,000.

## Project Overview

This project demonstrates a conversational voice agent that contacts existing customers, explains a potential loan offer, gathers eligibility information, and determines whether the customer meets the preliminary criteria for referral to a senior loan expert.

The agent is designed to conduct natural conversations, remember answers provided out of order, explain eligibility outcomes clearly, and avoid presenting preliminary qualification as final loan approval.

## Objectives

- Automate preliminary Loan Against Property qualification conversations.
- Collect the information required by the eligibility checklist.
- Identify ineligible cases and explain the relevant criterion.
- Route eligible customers to a senior loan expert.
- Route existing LAP or EMI-reduction requests to a specialist.
- Provide a polite, transparent customer experience.

## Technology

- **Voice agent platform:** Retell AI
- **Agent design:** Conversational flow
- **Interface:** Browser-based voice interaction through the published agent link
- **Documentation:** Markdown
- **Version control:** GitHub

## Key Features

- Customer greeting and identity verification
- Busy-customer callback preference handling
- Natural, conversational questioning
- Seven-item preliminary eligibility checklist
- Immediate handling of disqualifying criteria
- ₹75 lakh maximum requested loan amount
- Specialist routing for existing LAP and EMI-reduction cases
- Clear explanation before call termination
- Explicit distinction between preliminary eligibility and final approval

## Eligibility Checklist

| Requirement | Preliminary criterion |
|---|---|
| Property type | Residential, commercial, or industrial |
| Ownership | Sole or joint ownership |
| Original property documents | Must be available |
| Requested loan amount | Up to ₹75,00,000 |
| Occupation | Salaried or self-employed |
| Income receipt | Income must be received through a bank account |
| Property market value | Customer's estimated value is collected; no minimum is specified in the supplied checklist |
| Requested tenure | 3 to 15 years, inclusive |

Although the table lists eight rows, occupation and income receipt together form one checklist item in the seven-item assessment.

## Conversation Flow

1. Greet the customer and verify their identity.
2. Check whether the customer is available to talk.
3. Introduce the potential LAP offer and explain the preliminary nature of the assessment.
4. Check for existing LAP or EMI-reduction requests requiring specialist routing.
5. Collect and validate the seven required checklist items.
6. Explain any disqualifying condition and close politely, or complete the preliminary assessment.
7. Refer customers who meet all preliminary criteria to a senior loan expert
